One line of software error copy that tells the user the brutal truth about the failure and makes them laugh.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Error 418: the database did not crash, it simply gave up after reading your migration and decided to become a spreadsheet.
```
